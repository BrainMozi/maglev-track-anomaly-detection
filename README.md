# 磁域鹰眼

对磁浮线路监控画面做两件事：**YOLO26s 检测保护区内的人员、车辆；开放集方法检测轨面异物。**结果合成检测图和 JSON。

```text
监控画面
├─ 保护区 → YOLO26s → 人员、车辆
└─ 轨面 → 画面对齐 → 正常轨面特征对比 → 异物候选
                         → 像素差异与轮廓细化 → 异物区域
```

## 文件放在哪

```text
磁域鹰眼/
├─ src/       检测主链 {YOLO、轨面配准、异常识别、结果合并}
├─ scripts/   动手运行 {抽帧、YOLO训练、准备模型数据、逐帧检测}
├─ data/      数据说明 {七点位图像、人工标注、AI预标注的数量和用途}
├─ demo/      监控页面原型 {摄像头、告警、回看、台账}
└─ extras/    辅助材料 {参数示例、代码测试}
```

YOLO 数据现有 **3116 张图**，其中 **117 份人工精确框标注**；轨面异物数据 **3275 张图**，正常 **2151**、异常 **1124**，另有 **124 张人工圈定的异物区域**。AI 标注只作为下一轮人工标注的预标注。细分见 [`data/README.md`](data/README.md)。

图像与模型文件正按 Git LFS 加入同一仓库，完成后分别位于 `data/` 与 `runtime/`。
