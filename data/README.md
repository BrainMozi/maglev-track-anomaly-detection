# 数据说明

数据和 `runtime/` 运行资产在本仓库 [v0.1.0 Release](https://github.com/BrainMozi/maglev-track-anomaly-detection/releases/tag/v0.1.0) 中按目录分包。所需 ZIP 解压到仓库根目录即可还原下面的路径。

| 数据 | 数量 | 标注与用途 |
| --- | --- | --- |
| YOLO 已知目标集 | **3116 张图、3116 份标签**；训练 2174、验证 629、测试 313 | 检测人员、车辆。`annotations/ch07/` 中的 **117 份人工精确框标注**是人工标注；`prelabels/yolo/` 中模型生成的框**仅供后续人工标注使用**，不作为人工真值或评估依据。 |
| 轨面异物集 | **3275 张**；正常 2151、异常 1124，正常∶异常约 **1.91∶1** | `prelabels/open_set/` 中 AI 生成的 mask **仅供后续人工标注使用**，不作为人工真值或评估依据。 |
| 轨面异物人工标注 | **124 张** canonical 坐标 mask | `annotations/open_set_coarse/` 中人工圈定异物区域，用于开放集方法的区域参照；与 AI 预标注分开。 |

轨面异物集各划分的正常∶异常为：训练 **1525∶815**、验证 **426∶209**、测试 **200∶100**。

`annotations/ch07/` 保存 282 张原图，其中 117 张配有人工精确框标注 JSON。七点位场景图像在 `selected_frames/`，共 3011 张。
