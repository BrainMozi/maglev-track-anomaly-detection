# 发布文件核对

本地候选包将项目各层放在同一目录：算法源码、复现脚本、监控交互原型、七点位候选帧、ch07 初步标注、两任务预标注数据、ch07 运行资产、配置模板与测试。

正式发布时逐项核对：

1. 代码、现场影像、派生几何参数、模型权重和监控底图各自的授权范围与许可文本；
2. 公开文件清单和哈希、各目录实际文件数及单文件大小；
3. 真实图片及标签中的私人路径、身份信息与监控场景信息；
4. 模型输出的统计范围、训练与测试划分和预标注来源；
5. 从数据目录到运行资产、推理入口和演示原型的文档路径；
6. 最终 Git 跟踪清单、远端传输方式和团队仓库权限。

本文件与根目录 README 一同供负责人确认本地候选包内容。
