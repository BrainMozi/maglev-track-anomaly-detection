# 技术组成说明

当前联合单帧视觉链由以下部分组成：

1. **已知目标**：YOLO26s 在保护区 ROI 识别人员、车辆，输出类别、置信度与检测框。
2. **轨面坐标**：固定机位画面配准后映射到 canonical 轨面，保留各位置的空间对应关系。
3. **开放集候选**：WRN Layer2/Layer3 中层特征与逐位置正常记忆比较，高分种子标记局部偏离。
4. **像素边界**：颜色与梯度的正常统计生成像素证据，由 Graph Cut 得到候选轮廓。
5. **区域判定**：汇总局部热图、像素差异、形状和边界信息，形成最终异物区域。
6. **单帧汇总**：将已知目标框和未知异物 mask 写入统一 JSON 与叠加图。

源码分别位于 `src/maglev_anomaly/`，构建与处理入口位于 `scripts/`。详见 [METHOD.md](METHOD.md) 与 [UNIFIED_SINGLE_FRAME.md](UNIFIED_SINGLE_FRAME.md)。
